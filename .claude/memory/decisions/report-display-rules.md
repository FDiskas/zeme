**Decision:** Presentation rules in the report layer (refine [[ui-lithuanian-and-curation-layer]]):

0. **Card layout (2026-10-26, compacted after user review "pagriuvo dizainas").** Address is the h1; `Kadastrinis Nr.` is a small line under it with Kopijuoti (no dark ink band). Right after: risk tags for **attention flags only** (`flag.tag` wording) plus one green "N patikrinimų be pastabų"; "check" flags (SŽNS etc.) are in every report, so they stay in the list only. Then 4 `primary` facts in large 2×2 cells (plotas, paskirtis, pastatai, užstatymas with a green/red meter), the rest as one-line label/value rows (`FactRows`), Unikalus Nr. + coordinates folded under "Techniniai duomenys". Actions: PDF (primary) on its own row, Dalintis + KML in two equal columns, all 48px; refresh is a worded link "↻ Atnaujinti" beside "Duomenys atnaujinti …". "Svarbiausia trumpai" below the card is sorted attention → check → good, each row a round tone mark + label + a one-or-two-word answer (`flag.detail`: Rasta, Nerasta, Užbaigta, Daugiau nei aplink, Tikrinti atskirai). The longer answer (`flag.note`) shows only as a hover/focus bubble; no links in this list (they live in the detailed panel). Fact `hints` (paskirtis full name, užstatymas measuring note + allowed %, bendrasis plotas note) sit behind an `InfoTip` "i" beside the label, never under the value; the užstatymas meter is a slim bar with words only when over the limit. Opened detail panels are white sheets with a hairline edge; row hovers are square (rounded hovers clashed with the opened body).
0a. **No school/kindergarten on the card.** User asked (2026-10-26) to keep them only under "Aplinka ir kaimynystė": the `nearby-services` insight reads "Artimiausia mokykla ~X km, darželis ~Y km, gydymo įstaiga ~Z km tiesia linija." and names a lookup that brought nothing ("mokyklos duomenų negauta").
0b. **Partial panels.** A `partial` panel that still has items is shown as ok (nearby-services is partial when one of three lookups fails — it used to hide the whole panel). Only `GATED_PANEL_KEYS` (szns-restrictions) get the "check elsewhere" treatment.
1. **Identity numbers.** The header shows `Kadastrinis Nr.`; `Unikalus Nr.` sits under "Techniniai duomenys" (parcel "unikalus daikto numeris"). Parcel unique number comes from the `biip-boundary` item's `uniqueNumber`, surfaced via `findParcelUniqueNumber` in `report-format.ts`; hidden when noise/absent. Building list (`grpk-buildings`) shows `Unikalus Nr.` right after `Užstatytas plotas` — best-effort from OSP `pastatai_geo` (`uniqueNumber`, often "N/A" since that dataset is sparse).
2. **Unique-number formatting.** Displayed grouped with dashes: `440047566034` → `4400-4756-6034` via `formatUniqueNumber` (frontend-only; backend value stays raw). Applied to the parcel number and any field marked `isUniqueNumber: true` in FIELD_RULES.
3. **Paskirtis source.** Summary "Paskirtis" = `boundary.landUse` (BIIP `purpose.full_name`: "Kita", "Žemės ūkio"…), shown with its TPDR code + full name: "Kita (KT)" / hint "Kitos paskirties žemė…". BIIP `purpose_group.name` is always "Žemės naudojimo" (the group's name, not a value): the connector no longer emits it as `landPurpose`, and web + PDF never show it. TPDR codes (KT/Ž/M/K/V) are decoded in ASGR fields via `LAND_PURPOSES`.
4. **Šaltinis visibility.** `Šaltinis:` line is shown **only inside an expanded panel**, as the registry name + data date ("Duomenų data" where the source states one, else "Patikrinta <fetchedAt>"); the technical dataset id (ntr_sklypai…) hides behind an ℹ "Techninis pavadinimas" disclosure. The registry name links to its DATA_SOURCES `url` unless the host only serves machines (`MACHINE_ONLY_HOSTS`: boundaries.biip.lt Swagger, osp-sdg ArcGIS, maps.ird.lt 403). Per-record links: TPDR documents → TPDR map, heritage → KVR, permits → Infostatyba project page ([[infostatyba-project-links]]). Panels that found nothing and have no insight/note are merged per category into one "Nerasta: A, B" line; failed panels get "Bandyti dar kartą" (forceRefresh), gated SŽNS gets geoportal.lt + NTR links.
5. **Google Maps link.** Header (right side) has a "Žemėlapyje (Google)" link built from the parcel centre (`parcelCenter` → `maps/search/?api=1&query=lat,lng`); shown only when geometry is known.
6. **Flag tones.** `FlagState` = good (✓ green) / attention (⚠ tangerine) / check (ℹ neutral), with a sr-only spoken tone; details never a bare "Nėra" (use "Nerasta", "Nėra, tik …"). Section title is "Svarbiausia trumpai". Closed panel rows show a counted noun ("3 laikotarpiai", `ltCount`), none for one-record panels.
7. **Flags jump to detail.** Summary flags (Saugomos teritorijos, Kultūros paveldas, Taršos rizika, Specialiosios sąlygos) are buttons carrying a `panelKey`; clicking calls `revealPanel` which opens (`<details>.open`) and `scrollIntoView`s `#panel-${key}` (ids added in `ReportPanel.tsx`, `scroll-mt-24`).
8a. **Long lists.** Panels whose FIELD_RULES mark `inRow` fields render records as one-line rows (date · name · status · address) that open for the rest; from 12 records on they get search + year + document-type filters and "Rodyti daugiau" paging. Identical curated records are dropped (ASGR zones split into identical polygons, repeated Infostatyba rows). `asTags` fields (OSP protected/heritage names, joined with ", " upstream) become deduped tags, using other panels' `name`s to keep names that contain commas whole.
8. **Užstatytas plotas** leads with GRPK footprints (matches map + Pastatai panel); SSVA density (includes carports) is a hint only when ≥5 % larger. A failed RC valuation stays on the card as "Nepavyko gauti" + retry.
9. **Vidutinė rinkos vertė — IMPLEMENTED via RC masinis vertinimas.** Real per-object value scraped from `registrucentras.lt/masvert/paieska-obj` — see [[rc-masvert-market-value]]. Surfaced as the 4th summary fact ("Vidutinė rinkos vertė", after Pastatai sklype) + a `rc-masvert` detail panel (Daikto vertė / Vertinimo data / Pastaba). No value found → no fact (never fabricated).

**Why:** User feedback (2026-06-14).

**How to apply:** Field provenance + LT labels + formatters in `apps/web/src/lib/report-format.ts`; rendering in `apps/web/src/components/{SummaryCard,ReportPanel}.tsx`. Building unique number depends on server: `OspBuildingPoint.uniqueNumber` (osp-service.ts) → grpk item `uniqueBuildingNo` (connectors.ts); `pastatai_geo` field name unconfirmed (probes `unikalus_numeris ?? unikalus_nr`).
